🏏 Virat Kohli Performance Analytics Dashboard🎯

Purpose & Overview: 

This project is an interactive, data-driven analytics dashboard designed to visualize and analyze the ODI and T20 cricket performance of Virat Kohli. By filtering through various years , users can gain deep insights into his scoring trends, performance across different cricket grounds, opponent-wise statistics, and quarterly run distributions. It transforms raw cricket statistics into actionable, easy-to-interpret visual insights.

Key Features & Highlights:-

Yearly Timeline Filter:
Interactive top-bar navigation to seamlessly filter performance data from 2008 to 2022.


Geographical Insights (Top 5 Grounds):
A dynamic horizontal bar chart displaying total runs scored across top venues like Wankhede, The Oval, and Rajkot.


Ground vs Opponent Mapping:
A detailed matrix showcasing specific performance metrics against teams (e.g., Australia, New Zealand, Pakistan) mapped to the respective stadium.


Granular Time-Series Breakdown: 
A structured tabular view breaking down runs by Year $\rightarrow$ Quarter $\rightarrow$ Month for deep-dive trend analysis.


KPI Scorecards: Instant visibility into critical career/yearly metrics:
Total Runs 
Maximum Runs
Average 
Total Matches Played against opponents

Opponent Breakdown:

A dedicated section highlighting maximum runs scored against specific opponent teams (like Bangladesh and England) with trend indicators.
